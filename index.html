Pertanyaan Umum

Apakah butuh internet?

Tidak. Aplikasi jalan penuh secara offline. Internet hanya diperlukan bila pelanggan membayar lewat QRIS (dari sisi HP pembeli).

Data saya disimpan di mana?

Di perangkat Anda sendiri. Kami tidak menyimpan data penjualan Anda di server mana pun. Gunakan fitur Backup untuk mencadangkan.

Bisa dipakai di berapa perangkat?

Lisensi berlaku per perangkat. Untuk banyak kasir/cabang, tersedia harga grosir.

Printer apa yang didukung?

Printer termal 58mm & 80mm (ESC/POS) via USB, Bluetooth, atau driver Windows. Juga bisa cetak lewat dialog printer biasa.

Bagaimana cara aktivasi setelah beli?

Anda akan menerima kunci lisensi. Buka aplikasi → Pengaturan & Akun → 🔑 Lisensi Aplikasi → tempel kunci → Aktifkan. Selesai!

Apakah menerima pembayaran QRIS kena biaya kami?

Tidak dari aplikasi. Biaya QRIS (MDR) mengikuti penyedia QRIS Anda (mis. DANA), bukan aplikasi ini.
